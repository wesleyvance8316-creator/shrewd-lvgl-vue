# @APP_NAME@

Vue-style LVGL application, generated by `tools/new-app.sh`.

## Build & run

先在 **shrewd-lvgl-vue 仓**里把依赖与框架都装进同一个前缀(一次即可):

```
tools/fetch-deps.sh
tools/build-deps.sh                                   # 依赖 -> build/prefix
cmake -S . -B build -DCMAKE_PREFIX_PATH=build/prefix
cmake --build build
cmake --install build --prefix build/prefix           # 框架本身 -> 同一前缀
```

然后在**本仓**:

```
cmake -S . -B build -DCMAKE_PREFIX_PATH=<上面那个 build/prefix>
cmake --build build
./build/@APP_CNAME@
```

## Two entry points

| 形态 | 产物 | 入口 | 用途 |
|---|---|---|---|
| **默认** | 可执行 | `src/main.c` 的 `main()` | 开箱、调试 |
| `SHREWD_APP_AS_THREAD=ON` | 库 | `src/app_thread.c` 的 `gui_thread()` | 嵌入交付(业务主进程的一个线程) |

框架**不持有主循环**(design.md §9.2)——`app_step()` 是你要在自己的循环里戳的那一下。

## Layout

```
src/
├── app.c / app.h        装配:init + mount
├── main.c               入口 A(默认)
├── app_thread.c         入口 B(线程)
├── stores/              数据模型:结构 + reflect 描述 + 应用级共享 ref
├── components/          组件(一目录一组件)
├── views/               页面
├── composables/         复用逻辑
└── assets/              图片、字体
```
